# Handwritten Digit Classification

A classical Machine Learning project for classifying
handwritten digits (0-9) using the MNIST dataset.

## Objectives

- Understand image data representation.
- Perform exploratory data analysis.
- Implement classical ML algorithms.
- Implement selected algorithms using NumPy.
- Evaluate and compare model performance.
- Deploy the trained model using Flask.

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Flask
